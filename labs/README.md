# التعلم بالذكاء الاصطناعي دون فقدان المهارة: المختبرات

ثلاثة مختبرات لمقرر أكاديمية سدايا **USE-EDU-102**. المختبرات صفحات إرشادية بالعربية: الهدف، والملفات، وخطوات
بدقائقها وأوامر تُنسخ، وأسئلة تحقق، ومهمة إضافية ✱، وملاحظات للميسِّر. لا كود يكتبه المشارك.

كل المختبرات في جهة واحدة: **مركز دعم التعلّم في كلية الرِّواق التطبيقية**، كلية افتراضية، ومساعدها الدراسي «قَبَس».
كل الأسماء والمسائل والسجلات والأرقام مخترعة، عدا أرقام التجارب المنشورة في ملف الملخصات.

## ما يحتاجه المشارك

- متصفح، وحساب مجاني في مساعد ذكاء اصطناعي عام واحد. الخطة المجانية تكفي، ولا يُنزَّل أي نموذج على الجهاز.
- ورقة وقلم وآلة حاسبة بسيطة، للأجزاء التي تُؤدى دون ذكاء اصطناعي.
- للمختبر 1.3: مسألة من مقرره أو عمله، بلا بيانات شخصية. وإن لم يحضر مسألة فالمسألة ج من ملف المسائل.

## للميسِّر: المفتاح والأدوات

- `solutions/answer_key.md`: كل ما زُرع في الملفات، وأين، وأي مختبر يكشفه، وكيف يُقيَّم.
- `solutions/score_sort.py`: يقيّم ورقة تصنيف المختبر 1.2 بالمفتاح (نقطة للجانب ونقطة للنمط، من 16).
- `solutions/check_transcript.py`: يفحص سجل مرشد ببنود قائمة التحقق الأربعة: لا إجابة نهائية من المساعد قبل المتعلم،
  وتلميح واحد في كل رد، وطلب لإعادة الشرح، ولا بيانات شخصية. فحصه بسيط ومقروء، ولا يغني عن قراءة السجل.
- `solutions/stand_in_tutor.py`: نموذج بديل مكتوب، وليس نموذجًا لغويًّا. يكتب السجلين المرجعيين (مرشد يصمد، ومساعد
  تتسرّب منه الإجابة) ليُفحص الحل دون اتصال ودون مفتاح.
- `solutions/run_all.py`: يشغّل كل ما سبق ويطبع PASS أو أول اختلاف.

الأدوات مكتوبة بمكتبة Python القياسية وحدها، وتُشغَّل بـ`uv` من جذر المستودع:

```
uv run labs/_tools/prepare_files.py
uv run labs/solutions/run_all.py
uv run labs/solutions/score_sort.py labs/solutions/sort_sheet_reference.csv
uv run labs/solutions/check_transcript.py labs/solutions/transcript_reference.txt --answer 25
```

الأول يعيد كتابة `files/` وملفات الحل المرجعية ببذرة ثابتة (102): البايتات نفسها في كل تشغيل.

## ما لم يُشغَّل على نموذج لغوي

الخطوة 3 من المختبر 1.1 والخطوات 2 و3 من المختبر 1.3 تُؤدى مع مساعد حي، وسلوك المساعدات يختلف من نموذج لآخر
ومن شهر لآخر. السجلان المرجعيان هنا من النموذج البديل المكتوب. جرّب تعليمات `files/qabas_tutor_mode.txt` على
المساعد الذي ستستخدمه القاعة قبل أول دفعة، وسجّل هل تصمد أمام محاولات الضغط الثلاث.
